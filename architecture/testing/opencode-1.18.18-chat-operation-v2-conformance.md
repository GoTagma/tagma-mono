## Notes

- Do not infer SSE event type from the runtime payload alone; join the SSE id back to history.
- Apply the digest-authenticated ordinary text replay contract to classifier, discussion, and diagnosis only.
- Keep the legacy rich classifier scenario as negative evidence; production must never send `json_schema` or enable `StructuredOutput` for Chat routing.
- The control store schema version is 6, and schema mismatches fail closed.
- Packaged desktop metadata declares `chatOperationProtocolVersion: 2`; `runtime-paths.ts` emits `TAGMA_CHAT_OPERATION_V2_SHADOW=1` and `TAGMA_CHAT_OPERATION_V2_PRODUCTION_CUTOVER=2` only when that gate passes. Unsupported or contradictory handshakes fail closed.
- The GitHub Actions `managed-opencode-runtime` job runs the pinned native smoke and V2 question conformance checks on `ubuntu-latest`, `macos-latest`, and `windows-latest`; this document does not claim local macOS or Linux execution.
- Keep this matrix aligned with the authoritative ADR and the active Windows evidence set.
