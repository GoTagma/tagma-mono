## 确认的问题与回归边界

- **CSR-0025 / OBS-004：Trial 工具参数声明过宽。** 真实固定 OpenCode / Plugin 1.18.18 的模型参数含 `anyOf: [typed schema, {}]`，允许字符串，执行器却要求实际数组；多个不同业务场景反复命中。修复应将模型可见的类型声明与运行时不透明传输分开，保留错误完整提交的正式计数、身份/路径/版本校验及重复提交防护。禁止悄悄将 JSON 字符串转换成数组或放宽 Trial 内容检查。源码级 RED：两个新约束失败、九个原有边界控制通过。另有真实原生加载器 + 本地合成服务的隔离协议证据；它只证明工具协议，绝不代替真实供应商验收。
- **CSR-0026 / OBS-005：生成输入说明不完整。** 文案称必须 exact file-equals，但实现已支持 `present:true file-source-text-occurrence` 的 `sourcePath`，配合精确删除 fixture、生产者/消费者归属及依赖映射、独立具体生产者内容见证。修正文案和生成工具/Host 同步错误提示，保留所有上述约束；动态终端报告使用关系的 `path`，上游生成数据使用 `sourcePath`。
- **OBS-006：冷执行 unknown finish / 0 tokens 的归属未确认。** 现有 SDK 已正确拒绝无确定完成的模型结果。没有据此加入盲目重试、隐藏失败或放宽断言。Chat 模型选择也不能单独证明每个已生成 Prompt 的实际执行模型。
- 模型作者/规划错误、供应商限流、余额和免费策略拒绝、测试者预算中断分别保留，不宣称均由 Tagma 修复。
