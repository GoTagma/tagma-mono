The original files stay unchanged in the local workspace. Do not remove resolved issues or replace earlier failures with later results.

This public file contains metadata references, status, failure codes, budgets, model scopes and exact regression selectors. A matching SHA identifies evidence; it does not make an unavailable file verified in another workspace. Missing evidence stays unknown. Do not add the whole work directory to Git.
